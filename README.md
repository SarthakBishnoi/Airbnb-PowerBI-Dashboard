# Airbnb-PowerBI-Dashboard
📊 Airbnb Market Performance and Pricing Insights | Power BI Dashboard  This repository showcases an interactive Power BI dashboard developed to analyze Airbnb market performance across pricing, availability, occupancy, and geographic distribution. Tools Used  Power BI DAX, Data Modeling, Interactive Dashboard Design, BI &amp; Data Storytelling
🔍 Key Features
Executive KPI cards: Average Price, Availability Rate, Occupancy %, Total Listings
Monthly and yearly price trend analysis
Geographic visualization of listings by country
Top countries comparison based on average price
Interactive slicers for Year, Month, and Room Type
Cross-filtering, drill-through, and custom tooltips
🛠 Tools & Skills Used
Power BI DAX (KPI and analytical measures)
Data Modeling
Interactive Dashboard Design
Business Intelligence & Data Storytelling
🎯 Use Case
This project demonstrates how raw Airbnb listing data can be transformed into actionable insights for pricing strategy, market analysis, and performance monitoring. The dashboard structure follows a clear analytical flow—starting with a high-level overview, moving into geographic distribution, and concluding with comparative pricing insights.
